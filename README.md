<a id="key-features"></a>

### Core Functionality:
- **Flexible Interface** — Utilizes measurement units, rulers, and grids for precision.
- **Extensive File Support** — Compatible with over 100 file types including DXF, EPS, GIF, ICO, EXE, PSD, PDF, JPEG, RAW, TIFF, and AutoCAD files.
- **Image and Text Tools** — Includes image filters, text options, and vector objects to enhance your work.
- **Export in PDF** — Securely export your projects in PDF format with encryption and ciphering options.
- **CGM4 Engine** — Features support for WebCGM, expanding your presentation capabilities.
